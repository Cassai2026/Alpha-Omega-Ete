# CassWorld - Strengths-Based Learning Ecosystem

**Version:** 0.1  
**Author:** Paul Cassidy  

---

## Overview
CassWorld is a gamified, strength-first learning environment where players:
- Choose their Animus superpowers
- Complete missions and mini-challenges
- Gain life-value XP and unlock abilities
- Experience shadow traits and mentor AI guidance
- Learn financial literacy and ethical decision-making
- Engage with real-world inspired missions (community, innovation, empathy)

---

## Features
- Animus selection & abilities
- Mentor AI guidance: KONG, Hekete, ODIN
- Shadow traits and ethical challenges
- Life-value XP and real-world inspired currency/investment system
- Multi-zone exploration (neighborhoods, community hubs)
- Optional Flask deployment for browser-based play
